## 📖 About

This repository contains three mini projects I built as a first-year student to practice the fundamentals of front-end web development: page structure with **HTML**, styling and responsive layout with **CSS**, and interactivity with **JavaScript**.

Each project lives in its own folder with a separate `index.html`, `style.css` and `script.js`, and needs **no frameworks, no installation and no internet connection**.

---

## 🗂️ Projects

| # | Project | What it does |
|---|---------|--------------|
| 1 | [⏰ Digital Clock](./digital_clock) | Shows the current time and date, updating every second, with a 12-hour / 24-hour toggle |
| 2 | [💰 Expense Tracker](./expense_tracker) | Records income and expenses, shows the remaining balance, and saves data in the browser |
| 3 | [❌⭕ Tic-Tac-Toe](./tic_tac_toe) | Two-player 3×3 game with win and draw detection, a score counter and a reset button |

---

## ✨ Features

### ⏰ Digital Clock
- Live time that refreshes every second using `setInterval`
- Full date display (weekday, day, month, year)
- Button to switch between 12-hour and 24-hour format
- Responsive design for small screens

### 💰 Expense Tracker
- Add income and expense transactions with a description, amount and category
- Input validation (empty description or invalid amount is rejected)
- Automatic totals for income, expenses and balance
- Delete transactions and filter the list (All / Income / Expenses)
- Data is saved with **Local Storage**, so it stays after you refresh the page

### ❌⭕ Tic-Tac-Toe
- Two players take turns as X and O
- Detects all 8 winning combinations and highlights the winning cells
- Detects draws
- Running score for X, O and draws, with a New Game button

## 🚀 How to Run

1. **Clone or download** this repository
   ```bash
   git clone <your-repository-url>
   ```
2. Open the project folder you want (for example `digital_clock`)
3. **Double-click `index.html`** to open it in your browser

That's it. No server or setup is needed.
